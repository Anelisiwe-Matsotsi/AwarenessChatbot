## 👩🏿‍💻Code Overview

### ChatBot.cs
This class takes care of user input and responds using arrays. It gives replies both on screen with colour formatting and also speaks them out loud.

This includes:

- SpeechSynthesizer for voice responses.
- Keyword and response logic using arrays.
- Checks for valid input (like making sure name isn't empty).
  

### VoiceAssist.cs
This part plays the WAV file when the chatbot starts and sets up the voice to be female. It manages all the text-to-speech stuff.

### AsciiArt.cs
Just adds a bit of fun to the program. It shows a banner at the beginning to make the startup more visually interesting.
